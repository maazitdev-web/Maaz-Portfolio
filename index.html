E-COMMERCE WEBSITE

YourShop — Online Shopping Platform

A modern e-commerce website designed to provide customers with a smooth and convenient online shopping experience.

HTML5 CSS3 JavaScript Node.js MySQL
Live Demo GitHub

Project Overview

YourShop is an online shopping platform featuring product browsing, product details, shopping cart functionality and a checkout experience.

Key Features

  • Product browsing and categories
  • Product detail pages
  • Shopping cart functionality
  • Checkout and order confirmation
  • Responsive website layout

Technologies Used

  • HTML5 — Website structure
  • CSS3 — Styling and responsive layouts
  • JavaScript — Interactive functionality
  • Node.js and Express — Backend development
  • MySQL — Database

Development Process

The project involved planning the website structure, designing the shopping interface, developing interactive frontend features, and working on backend functionality.

Challenges & Learning

Building this project helped me practice JavaScript DOM manipulation, managing shopping cart data, organizing website files, and connecting frontend and backend functionality.
